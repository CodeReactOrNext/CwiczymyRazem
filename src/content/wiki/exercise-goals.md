A goal is one exercise and one tempo you want to play it at. You set it yourself, you decide how clean a run has to be, and nothing changes it for you. The only way to reach it is to play it.

## Setting a goal

<ClickPath steps="Progress|Goals|New goal" caption="Pick an exercise, the tempo to reach, how clean a run must be and how the clean runs add up." />

Goals work on exercises that have a tablature and a metronome tempo, because those are the ones the microphone can score note by note. Hunts, strumming patterns, listening quizzes and songs can't take a goal.

The tempo starts at the top of the exercise's own range. Change it to whatever you're aiming for. Each exercise holds one open goal at a time.

<StepList steps="How clean::Relaxed counts a run at 80% accuracy, Standard at 90%, Strict at 95%|Three clean runs::In a row means a run that isn't clean starts the count over. In total means clean runs add up, whatever happens between them" />

## Playing in goal mode

<ClickPath steps="Progress|Goals|Start goal run" caption="Opens the exercise with the metronome at your goal's tempo." />

A goal run is the exercise played for its full time with the microphone on. When the timer runs out, the summary tells you whether the run was clean and how many clean runs you have. Press **Try again** for the next run.

A run counts at the slowest tempo it was scored at. You can slow the metronome down for a warm-up run, but that run won't be clean, because it wasn't played at the goal's tempo.

<ProgressLadder items="Run 1 clean::1 of 3|Run 2 clean::2 of 3|Run 3 clean::Goal reached" highlight="Run 3 clean" />

<BlogAlert type="info">
Only goal runs can reach a goal. Ordinary practice of the same exercise still shows up on the goal's chart, so you can see the way up, but it never counts toward the three clean runs.
</BlogAlert>

## The chart

Every goal shows your fastest run so far against the goal's tempo, and a chart of your scored runs on that exercise with the goal's tempo as a dashed line. Small grey dots are ordinary practice, green dots are clean goal runs, and hollow dots are goal runs that didn't count.

The chart starts before the goal does: sessions where you practised that one exercise with the microphone on show up too, so a new goal opens on the climb that led to it. Sessions of a routine with several exercises don't, because the score can't be pinned to one exercise.

Switch the chart to **Timing** to see how precisely you play rather than how fast. Each run shows how far your notes typically land from the beat, in milliseconds, and the higher the dot, the tighter the run. The shaded band at the top is dead on, within 25 ms. Hover a run to see whether you tend to play ahead of the beat or behind it.

<BlogAlert type="tip">
If every run leans the same way, ahead or behind by about the same amount, that is usually your audio delay rather than your hands. Run the timing calibration once, see note detection.
</BlogAlert>

## When you reach it

The goal moves to **Reached**, the feed tells everyone, and the exercise's **Speeds mastered** are ticked up to the goal's tempo. Coming back from the run, you're asked whether to raise the bar: the next goal starts about 10% faster, and you can change it before saving. Reached goals stay in the list, and the latest one for each exercise keeps a **Raise the bar** button.

Goals don't give points or Fame. The practice time of a goal run logs like any other session.
